# Chinmayi Subramanya — academic website

A lightweight, responsive academic website for Chinmayi Subramanya. The site is built with plain HTML, CSS, and JavaScript so it can be hosted directly with GitHub Pages without a build step.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Structure

- `index.html` — content and page structure
- `styles.css` — visual system and responsive layouts
- `script.js` — navigation, reveal effects, and subtle network motion
- `assets/` — portrait, CV, and favicon

The repository is ready for GitHub Pages, but no deployment configuration or public publication has been performed.
