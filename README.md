# Chinmayi Subramanya - Academic Website

Source code for my personal academic website, documenting my research, academic activities, and interests.

I am a doctoral researcher at the [Max Planck Institute of Molecular Cell Biology and Genetics (MPI-CBG)](https://www.mpi-cbg.de/) in Dresden, Germany, as part of the [International Max Planck Research School for Biology, Mathematics, AI, and Physics (IMPRS-BioMAP)](https://imprs.mpi-cbg.de/).

My research focuses on the mathematical and physical characterization of complex biological flow networks, particularly their three-dimensional organization, interconnectedness, and implications for physiological function.

## Website contents

- **About:** Academic background and research interests.
- **Research:** Current research focus, mathematical approaches, and manuscripts.
- **CV:** Academic qualifications and awards, with a downloadable PDF.
- **Course catalogue:** Selected coursework from my integrated BS-MS degree in Physics.
- **News:** Research updates and academic activities.
- **Miscellaneous:** Other interests beyond the lab.
- **Contact:** Professional contact information and relevant links.

## Technical details

The website is built using HTML, CSS, and vanilla JavaScript, without external frameworks or a build system.

The repository is organized as follows:

```text
.
├── index.html       # About and research
├── awards.html      # CV, awards, and fellowships
├── courses.html     # Course catalogue
├── news.html        # News and academic activities
├── beyond.html      # Outreach, music, and other interests
├── contact.html     # Contact information
├── styles.css       # Styling, themes, and responsive layouts
├── script.js        # Navigation and interactive features
└── assets/          # Portrait, CV, favicon, and other assets
```

### Local preview

Clone the repository:

```bash
git clone https://github.com/cchinmayii/cchinmayii.github.io.git
cd cchinmayii.github.io
```

Start a local HTTP server:

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

Open [http://127.0.0.1:4174](http://127.0.0.1:4174) in a browser. If the browser shows an older version of the site, perform a hard refresh.

## Deployment

The website is designed for static hosting through GitHub Pages. No compilation or additional build configuration is required.

GitHub Pages deployment has not yet been enabled.
